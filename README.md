# pi-project-plugin

在 pi-coding-agent 中复刻 Claude Projects (beta) 的主要功能。

## 目标

为 [pi-coding-agent](https://github.com/earendil-works/pi) 提供类似 Claude Projects (beta) 的能力，例如：

- 项目（project）级别的组织与隔离
- 项目专属的系统提示词 / 指令
- 项目内的会话（thread）管理
- 项目知识库（上传文件、参考资料）

具体功能范围与架构在开发过程中逐步确定。
